## 2026-09-30 daemon 进程树监控

- 两个运行程序共用 Windows Job Object 跟踪直接启动进程及全部子孙进程。目标以挂起状态创建，加入 Job 后才恢复执行，避免短命启动器的竞态；只有活动进程数归零才自动退出。未启用关闭 Job 时终止进程的选项，工具提前退出不关闭游戏。
- 用户态移除直接进程句柄的退出等待，改为在约 50 ms 的维护周期查询整棵进程树；内核态沿用约 4 ms 的检查周期。无法创建或加入 Job 时取消启动并报错，不降级为单进程监控。
- 在忽略的 `build/` 目录编译并运行临时 Win32 检查程序，通过启动器快速退出、子进程延迟创建孙进程后退出、孙进程退出但另一分支仍存活、全部进程退出、提前销毁监控仍可创建并运行后代、连续 10 次立即退出和无效 EXE 路径检查。未新增产品测试或诊断 target。
- 使用 x64 MSVC、CMake/Ninja 完成 Debug / Release 三个 EXE 的构建与链接，未见编译警告；`git diff --check` 通过。输出位于 `build/debug/bin` 与 `build/release/bin`，未更新安装目录或发行包。
- 未执行真实输入映射、驱动操作、Steam、游戏或反作弊验证。由已有客户端或系统服务代为创建的外部进程不在目标进程树内；要求脱离 Job 的启动方式可能不兼容，常驻后代会使工具继续运行。

## 2026-09-27 运行时低延迟优化

- 两个运行时的采样历史改为可复用连续环形队列；按窗口长度预留两倍 8 kHz 容量，超出后扩容而不丢样本。实体键所有权改用设备位掩码，鼠标设备状态改用带最近索引缓存的连续表。保持阈值、平滑、曲线、脉冲与键位配置含义。
- 普通方向释放纳入最近期限。用户态增加高分辨率一次性等待定时器与停止事件，消息批次限制为 32 条或 0.5 ms，并在输入期间维护定时状态；期限后移时复用较早的已设定定时器。内核态继续使用官方 DLL 的毫秒等待与即时逐包输出，复用接收缓冲，并将游戏进程查询限制到约每 4 ms 一次。增加可选 `--input-priority normal|above-normal`，默认不提权。
- 运行监视改为 GUI 租约订阅，未订阅时不创建大型事件环、不逐包发布监视事件，约每 50 ms 检查小型控制区。事件数据仍只读，订阅控制区独立，协议升级为 v2。GUI 切页/最小化/退出退订，暂停画面保持订阅；异常退出约 1 秒后租约失效。
- 修改前保存当前共享状态机头文件到忽略的 `build/latency-baseline`，临时离线程序分别用前后版本编译。16 组场景覆盖 125/1000/4000/8000 Hz、长按、脉冲、曲线、平滑、快速反向、双轴、按钮、滚轮及多鼠标；每组 262,144 包。前后按键事件数量及有序校验值全部一致。预留容量内的热路径动态分配从每组约 67.6 万至 134.2 万次降为 0；另验证最长 4 秒积累窗口下的 8 kHz 输入无需扩容，以及环形队列扩容、回绕和设备缓存失效。
- 一次本机 `/O2` 离线对比中，8 kHz 长按场景的批次平均每包耗时中位数约 264 ns → 47 ns，P99 约 331 ns → 61 ns；曲线场景中位数约 211 ns → 50 ns。每批 64 包、共 4,096 批，这些是**批次均摊 CPU 耗时分布**，不是单事件尾延迟，也不包含真实 Raw Input、SendInput、驱动调用、设备到达等待或游戏响应。数值受本机负载影响，不作端到端延迟承诺；官方 Interception DLL 内部堆分配仍保留。
- 临时内存接收器验证反向先释放、物理键持有保护、失败后释放重试、多鼠标移除和滚轮；模拟用户态回调验证 Raw Input 读取失败、SendInput 失败、注入事件回环排除与清理。监视检查使用带独立后缀的共享内存对象，覆盖无订阅不分配事件环、双读者、退订、重新订阅、子进程不执行析构直接退出后的租约回收、运行时重启及停录。
- 独立检查实际 Windows 等待定时器、期限已到/不足 1 ms 的等待计算、期限后移不反复重设、模拟创建/设置失败后的毫秒回退，以及输入线程优先级设置与恢复。一次 50 次、每次 1.5 ms 的空闲定时器检查最大迟到约 1.09 ms；仅反映该次调度环境，不能作为硬实时保证。
- 所有临时检查均位于忽略的构建目录，未新增 CMake 测试或诊断 target；未注入真实键盘输入，未操作真实驱动，未进行 GUI 自动化、真实高回报率鼠标、Steam、游戏或反作弊验证。
- 使用 x64 MSVC 19.50、CMake/Ninja 完成最终 Debug / Release 三个 EXE 的构建与链接，未见编译警告；两个运行时的 Release 构建命令确认包含 `/GL` 与 `/LTCG`。四个终端构建均通过 `--input-priority above-normal --help` 和非法优先级参数拒绝检查；相关文件 `git diff --check` 通过。未更新安装目录或生成发行包，当前输出位于 `build/debug/bin` 与 `build/release/bin`。
